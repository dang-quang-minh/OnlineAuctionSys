	+ Minh: Xây dựng server.service, server.network
	+ Mạnh: Xây dựng client.controller và client.view
	+ Lâm: Xây dựng server.repository, common.exception và client.network

- Công việc (tuần 9):
	+ auction-common:
		~ common.model: Viết chi tiết cấu trúc các thực thể OOP gồm User (Bidder, Seller, Admin); Product (Art, Vehicle, Artifact), ProductFactory, Auction, Bid và các giao diện cho cơ chế Observer (Notify/Subject).
		~ common.dto: Thiết kế các lớp đóng gói dữ liệu trao đổi qua mạng (LoginDTO, BidDTO, AuctionDTO) và lớp định tuyến gói tin NetworkMessage để Server phân loại yêu cầu.
		~ common.exception: Tạo các custom exception phục vụ kiểm tra lỗi nghiệp vụ (InvalidBidException, AuctionClosedException, AuthenticationException).
	+ auction-client (Xây dựng các màn hình cơ bản của ứng dụng desktop, sử dụng chuẩn mô hình MVC, hoàn thiện GUI bằng FXML):
		~ client.controller: Điều khiển giao diện và xử lý sự kiện người dùng, áp dụng Platform.runLater() để cập nhật bảng giá hiển thị an toàn từ luồng mạng.
		~ client.network: Thiết lập kết nối Socket Client và xây dựng luồng nền (Background Thread) lắng nghe phản hồi liên tục từ Server.
		~ client.view: Thiết kế giao diện đồ họa trực quan bằng các tệp tin cấu hình .fxml (Màn hình Đăng nhập, Màn hình chính, Phòng đấu giá).
	+ auction-server (Cài đặt các cơ chế xử lý đa luồng và đồng thời tại project này):
		~ server.network: Kết nối server với client qua mạng Socket, sử dụng Thread Pool (ExecutorService) để quản lý đồng thời nhiều kết nối ClientHandler độc lập.
		~ server.repository: Triển khai cơ chế tuần tự hóa dữ liệu Serialization để lưu trữ và tải trạng thái hệ thống từ file cục bộ.
		~ server.service: Viết bộ quản lý trung tâm AuctionManager xử lý logic nghiệp vụ đấu giá, tích hợp ReentrantLock và ConcurrentHashMap để bảo vệ luồng dữ liệu khi có đấu giá đồng thời. Viết Unit Test bằng JUnit 5 cho tầng dịch vụ này đảm bảo code coverage >= 60%.

	+ Tiến hành tái cấu trúc mã nguồn (Refactor code), loại bỏ các mã xấu (code smells) và áp dụng các nguyên lý thiết kế SOLID.
	+ Cấu hình Maven quản lý tập trung các thư viện phụ thuộc (dependencies), hỗ trợ build tự động; tích hợp công cụ checkstyle để ép tuân thủ coding convention; thiết lập kịch bản tự động hóa kiểm thử trên GitHub Actions (CI/CD).
	+ Triển khai hoàn thiện kiến trúc Client-Server hoạt động ổn định bằng Java Socket.

- Kiến trúc:
	+ auction-common:
		~ common.model: các lớp cốt lõi để định hình nên chuyên môn và luật chơi của ứng dụng đấu giá trực tuyến.
		~ common.dto: các lớp dữ liệu thô phục vụ việc đóng gói thông tin truyền nhận giữa Client và Server.
		~ common.exception: các lớp ngoại lệ tự định nghĩa dùng để bọc lỗi logic của hệ thống.
	+ auction-client:
		~ client.controller: bộ điều khiển giao diện, tiếp nhận sự kiện tương tác từ người dùng.
		~ client.network: cổng kết nối chịu trách nhiệm đọc/ghi luồng byte qua Socket phía client.
		~ client.view: tầng hiển thị giao diện đồ họa người dùng JavaFX (GUI).
	+ auction-server:
		~ server.network: cổng phân phối mạng, lắng nghe kết nối và điều hướng dữ liệu qua Socket phía server.
		~ server.repository: tầng xử lý lưu trữ dữ liệu bền vững ra file vật lý qua luồng I/O.
		~ server.service: bộ não trung tâm của Server, điều khiển việc đấu giá và xử lý đồng thời (AuctionManager sẽ nằm ở đây).
